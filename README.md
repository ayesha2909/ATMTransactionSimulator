# ATM Transaction Simulator

A desktop-based ATM simulation application developed using Core Java, Java Swing and AWT.

## Features

- Account number and PIN authentication
- Balance enquiry
- Cash deposit
- Cash withdrawal
- Transaction history
- Local account data persistence
- Logout functionality

## Technologies Used

- Core Java
- Java Swing
- Java AWT
- OOP Concepts
- HashMap
- File Handling
- Serialization

## Demo Credentials

| Field | Value |
|---|---|
| Account Number | 1234567890 |
| PIN | 1234 |
| Initial Balance | ₹10,000 |

## How to Run

Compile:

```bash
javac -d out src/*.java
```

Run:

```bash
java -cp out Main
```
